## 页面与资料

首页以摄影场景开场，保留节目、课程与制作记录三个项目入口。
继续展开报价演示、五套课程海报、活动、问答群、Bono 与近况。
导航另有作品、资料阅读、搜索与参与入口。

五类业务都有详情页：

- 多人喜剧聊天节目。
- AI 与 Codex 课程。
- BB箱子问答群。
- 内容型活动。
- 作品与公开制作。

资料区目前有 28 篇文章。
它们按节目、人物、参与与规则、方法与模板、制作近况分类。
正文包含目录、关联文章、表格与附件。
搜索匹配公开目录与正文，不发送远程检索请求。
搜索词会进入当前浏览器的页面地址与历史。
应用没有把搜索词送到统计服务。

七份 Markdown 下载资料已放入 `public/downloads/`。
收入分配和录制授权仍标为讨论草案。
课程 PPT 样稿也在该目录，文件内有 14 页。
文章 JSON 与索引 CSV 位于 `public/data/`。
下载存在不代表材料已获用户接受或对外发布。

## 三维舞台

入口是首页“走进三维舞台”按钮。
进入前保留场景图，按下后才加载三维模块。
当前代码创建三维物件、灯光与阴影。
用户可选择主舞台、聊天桌、工作台和制作台。
相机连续朝所选区域移动。

桌面与窄屏使用不同的相机位置。
页面有暂停、继续、重播和回到场景图的控件。
减少动画设置启用时，使用静态画面。
WebGL 初始化失败或失去上下文时，也回到静态画面。
这些分支需要在实际目标浏览器中复查。

舞台是概念空间。
它不是实际录制场地，也不是已有节目的证明。

## 报价交互

数据来自 `src/quote-model.js`，全部为合成资料。
比较采用首年含税口径，单位为万元。
初始结果如下：

| 方案 | 基础报价 | 附加费用 | 首年总成本 |
| --- | --- | --- | --- |
| A | 8.8 万元 | 7.0 万元 | 15.8 万元 |
| B | 10.2 万元 | 0 万元 | 10.2 万元 |
| C | 9.5 万元 | 接口费用未报价 | 待补齐 |

修改基础报价或附加费用，会更新表格与成本图。
报告与 HTML 汇报预览读取同一份计算结果。
缺失或无效费用不会按零处理。
不完整的方案不进入完整报价排名。
同价最低方案会一起列出。

CSV 由当前输入生成。
文件下载使用 `/downloads/quote-demo.csv`。
开发预览与托管 Worker 使用同一份计算。
纯静态托管需要另行适配此接口。
页面上的报告与汇报是 HTML 内容。
已有课程 PPT 是单独的静态样稿文件。
报价交互本身不生成 Word 或 PPTX 文件。
当前页面没有接入原始报价文件上传、AI 提取或真实业务审批。
真实资料需要提取、核对来源并由人复核。

## 业务与参与边界

课程核心范围以业务文档为准。
线上 199 元，深圳线下 399 元。
课时、场次、地点、平台和权益，按对应活动确认。

问答群为 199 元／年，处于预售期筹备。
起算、退款、续费与赠群条件，仍需统一。
乱讲 PPT 保留活动形式方向。
具体玩法、排期和价格，需在活动页说明。

五类参与入口使用既有飞书公开表单。
它们分别对应聊天、制作、场地、话题与合作。
报名数据由飞书处理。
2026-09-21 的测试记录是历史记录。
本次范围说明没有重新提交表单或验证后台收件。
