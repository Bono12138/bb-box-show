# 内部统计与运行说明

## 当前状态

GitHub Pages 只提供静态页面。`analyticsEnabled` 为 false，当前不收集网站访问事件。飞书工作台记录真实表单收件和后续参与情况。

`server/` 的接口、存储与鉴权已实现并有自动测试。妙搭缺少 `spark:app:read` 权限，官方脚手架与托管运行能力尚未接入。这是可自托管的 Node 服务，尚未在公开环境运行。

## 指标口径

| 记录 | 能说明什么 |
| --- | --- |
| page_view | 服务收到一次页面访问事件；不是独立人数 |
| engaged_read | 页面打开 30 秒时仍处于前台；不是读完 |
| form_outbound | 点击外部表单；不是提交 |
| contact_copy | 复制微信号成功；不是加好友 |
| download | 点击下载链接；不是读完文件 |
| 飞书表单记录 | 实际收到意向；不是已加入 |
| 有效意向 | 负责人确认可联系且符合当前方向 |
| 首次、再次参与日期 | 实际见面或交付，并有结果依据 |

跨站表单无法可靠逐人关联，不计算精确的访问到报名转化率。重复意向由真人核实合并。

## 运行服务

要求 Node.js 22.13+、持久化目录和 HTTPS 反向代理。默认只监听 127.0.0.1:4174，供同机代理接入。只暴露 `dist/client`，不能把项目根目录设成静态目录。

```sh
npm ci
npm run build
npm start
```

统计默认关闭。启用前，在受保护的运行环境设置 `BB_ANALYTICS_ENABLED=true`、真实域名的 `BB_SITE_ORIGIN`、至少 32 字符的随机 `BB_ADMIN_KEY`，以及静态目录之外的 `BB_DATA_DIR`。`PORT` 可覆盖默认端口。凭证不进入仓库或浏览器配置。

真实站点接口验收通过后，再打开前端 `analyticsEnabled` 并重新发布。Pages 不支持这项服务，保持关闭。

内部查询页 `/admin/` 调用 `GET /api/admin/stats`，必须带 Bearer 管理密钥。页面不保存密钥。隐藏地址和 noindex 不是权限控制，服务端鉴权才是。

## 数据边界

`POST /api/events` 只接收预定事件、公开站内路径、固定渠道标签、随机短期会话和参与类型。拒绝未知字段。不保存搜索词、故事、联系方式、录屏、User-Agent 或原始 IP；不做设备指纹。

30 分钟无活动后更换会话，关闭标签页后 sessionStorage 失效。尊重关闭统计、DNT 和 GPC。内部与测试浏览器应关闭统计；已识别机器人不入库。匿名事件仍可能被伪造，不能据此承诺人数或计算报酬。

原始事件保留 30 天，按日汇总保留 12 个月，使用北京时间。定时及写入、查询时清理。备份也必须遵守保留期。

IP 只短暂用于内存限速，不写入数据库。托管商或代理可能另有网络日志，启用前检查并缩短可配置的日志保留期。代理后方的限速须按实际拓扑复核，不盲信外部 X-Forwarded-For。

## 启用前检查

验证正确来源、非法来源、私人字段、超大请求、重复事件、机器人、错误密钥、关闭采集和保留期。接口故障不得影响阅读和表单。切换主站前，仍须测试国内 Wi-Fi、移动网络和社交应用内访问。
