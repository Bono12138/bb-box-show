# AI／Codex 课程宣传制作方案

更新：2026-09-25。状态：制作方案与文案草稿；尚未生成最终海报或上架活动。

## 制作要求

线上 199 元与福田线下 399 元共用核心课程。每套宣传材料完整说明课程、讲师、课前协助、学习权益、费用与报名方式。不同套装调整卖点优先级，而不删减产品内容。

## 五套完整宣传策略

以下标题为文案初稿，五类人群和宣传方向来自已认可的讨论。

| 套装 | 封面方向 | 先展开的内容 |
|---|---|---|
| A：尚未开始使用 | 想用 ChatGPT，却卡在了第一步？ | 课前协助、开始使用、作品，再介绍完整课程 |
| B：白领工作提效 | 开了 ChatGPT 会员，工作怎么还是自己干？ | 资料、文档、PPT、重复任务与工作流 |
| C：Vibe Coding 发布 | AI 把代码写出来以后，然后呢？ | 部署、公开网址、留资、统计与商业化准备 |
| D：创作者与项目发起人 | 把脑子里的想法，做成别人能打开的作品。 | 想法、制作、发布与用户反馈 |
| E：已有 AI 使用经验 | 从会用 ChatGPT，到搭起自己的 AI 工作台。 | 规则、Skills、MCP、多 Agent 与自动化 |

制作建议：五种策略分别适配线上和线下，形成十个独立发布版本。组图支持拆分发布和拼成长详情页；最终张数与尺寸按平台要求确定。

A 套示例顺序：开始使用的门槛 → 课前协助 → 作品 → 讲师 → 完整课纲 → 权益 → 报名。

C 套示例顺序：代码之后的发布问题 → 上线作品与商业化准备 → 讲师项目 → 完整课纲 → 课前协助 → 权益 → 报名。

## 共用服务文案草稿

> 教学使用 Codex，从用上到用好。活动开始前，会协助大家完成网络环境、账号与产品订阅准备。

发布前落实实际支持方式，说明第三方费用及服务适用条件。协助准备不应被写成保证所有账号或网络问题均可解决。

搭配 BB 箱子网站、脱敏管理系统和实际 PPT／文档／工作流截图。职业履历、教学人数、课程效果只使用本人确认或有依据的内容；活动负责人身份不延伸为官方认证讲师或品牌课程背书。

## 制作清单

1. 完整课程与卖点母版：所有内容、学习成果、服务和费用说明。
2. 两份取伙详情：线上、线下各自对应的时间、价格、地点／平台及报名流程。
3. 五套完整宣传组图，分别适配两种活动；封面与内页顺序按受众调整。
4. 讲师介绍卡、真实作品展示、FAQ 和报名后步骤。
5. 课程 PPT、讲师流程、跟练手册、素材、课前检查表与课后资料。

视觉建议沿用 BB 箱子的奶油色、黑色和橙色，以真实作品和克制的 BB 兔标记形成识别。最终视觉由实际样稿确认。

## 上架检查

- 日期、课时、容量和线上平台明确。
- 课前支持人员与流程落实。
- 工具费用、赠群、回看、退款与未成行处理写清楚。
- 全部宣传版本的课程和权益一致，分别指向正确的线上或线下活动。
- 真实图片取得使用许可，个人信息脱敏。
- 检查手机端全部文字的断行与可读性。
- 活动实际发布并回读后，才记录为已上架。
