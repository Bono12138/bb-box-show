## 已执行的纠正
- 不再把片尾当独立广告制作。正文20秒、片尾6秒，整片候选26秒。Kimi的28秒尾段已淘汰。
- 用户说的是20多秒整片；25秒或4–5秒片尾是助手此前提议，不是用户锁定时长。本轮以26秒试验明确介绍与短尾段的折中，不能声称6秒已经批准。
- 品牌片尾可复用，无我们的真人、真人录音或剧情依赖；本期信息是喜剧聊天节目招募，与BB箱子的课程社群等业务分开。
- 简介直接出现罗永浩《X字路口》与深圳南山，不再以抽象“共创/组局”替代说明。
- 不再让Kimi承担主设计责任。它是可选工具；此轮设计与取舍由dot完成，未继续调用Kimi。

## 这次交付是什么
1. 全片26秒静帧节奏预演：用已有分镜图按实际剪辑时长停留，接6秒代码片尾。用来检查全片比例、场景顺序和信息阅读时间。**正文不会动，不能用它评判生成动作、镜头质量或最终音乐。**
2. 片尾6秒动效测试：0–0.65秒字标；0.65–5.25秒介绍页；5.25–6秒字标收尾。避免密集闪烁，信息页停留4.6秒。
3. 全片时间线图片与片尾对照图。
4. 可编辑Python源文件。此版540×720只是低成本审阅输出，不是最终1080×1440交付。
