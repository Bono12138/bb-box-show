# BB箱子阶段1：原作摄影、运动与节奏复核

保存时间：2026-09-30 16:18 UTC。范围仅为本项目参考006、007、009；不混入其他独立学习。本文是视觉复核，不是声音审片结论。重点连续帧已经保存，本轮没有扩展到其他参考作品、付费生成、外部API或用户电脑。

## 先给导演结论

1. 荒诞感主要来自“正常人继续做正常动作，异常物真正发生运动”，而不只是把奇观摆在画面里。客机有破水、爬升、水花回落，冲浪者有接近、失焦、再被找回、上浪转板；只有静帧缩放不能复现这些事件。
2. 推拉不是全片恒定的动效。有效运动有明确对象：接近人的动作、拉开看关系、追随异常物、借前景遮挡让摄影机像临场观察者。最有价值的是“动作发生后，摄影机才反应”，并保留反应迟半拍的短暂不完美。
3. 007弹奏手术不是“先头部近景后拉远”：F298先见患者、班卓琴与医护，随后推向头部，再迅速拉开成手术室全景。工地图纸则是人群建立→推近简笔画→上移看建筑→回图纸，靠机位注意力往返形成笑点。
4. 006片尾不是把最后一镜停住再接Logo。F501叠标时背景仍在甩动；F513只把背景切黑，Logo位置、尺度基本锁定；F549才换工具署名。叠标12帧约0.500501秒，黑底Logo36帧约1.501502秒。
5. 有两处旧概述需纠正：009的F0–F1是快餐打斗闪帧，F2才进河面；006的预告快切到F37为止，台球主体从F38（1.584918秒）开始，旧“1.4秒开始正文”只能算粗略抽样，不能用作精确剪点。

## 4. 本期可执行的五个导演方法

以下是针对20多秒BB箱子短片的导演提议，不是对原作者真实工作流的证明，也不是用户已批准的时长与剧情。

### 方法一：给每个荒诞镜头一个真实的动作弧，先写主体，后写摄影机

- 执行：镜头卡至少写“进入时状态→一项主动作→镜尾可见后果”。生成时要求手脚、物体、环境结果一起动；摄影机运动只是跟随／取景，不能拿Ken Burns缩放充当全部动画。
- 可直接参照：009 F20–F60（0.666667–2.000000）客机破水→爬升→水花拖下；009 F151–F215（5.033333–7.166667）冲浪者接近→取平衡→上浪转板；006 F228/F240/F252/F264抽检，墙从小洞变碎、河马体积进入。
- 验收：三张关键帧里不只是主体变大，身体／部件姿态和环境结果也不同；播放时有动作方向与重量变化。
- 误判边界：原片为AIGC，动作可能违反物理；这里学的是可读动作发展，不替原片补造物理正确性或镜尾未出现的后果。

### 方法二：让摄影机被异常吸引，允许短暂追丢，但尽快找回

- 执行：先留足日常空间参照，异常发生后再上仰／跟随。只在一次关键跟随里允许极短失焦或擦过主体；之后必须有清楚的再定位帧。不要全片套随机抖动。
- 可直接参照：009 F2–F19（0.066667–0.633333）桥和遛狗者建立日常；F34–F60（1.133333–2.000000）追上客机；洪水F168–F182（5.600000–6.066667）靠近后失焦／丢失，F191–F197（6.366667–6.566667）找回。
- 验收：关闭摄影机特效也仍有主体事件；关键异常在短暂模糊前后各有清晰可辨时刻；镜尾不在不可读糊团上停很久。
- 误判边界：看到模糊不能证明作者有意“追丢”；这是一种可复用的观感结构。也不能据模糊断言连续一镜无内切。

### 方法三：用推拉或注意力往返读出荒诞关系，关系读清后停半拍

- 执行：当笑点依赖尺度或上下文时，镜头先看动作或细节，再拉开环境；如果依赖“图上／现实”的对照，移动注意力在两者之间。每镜只选一项主关系，留一个短暂较稳的读取段。
- 可直接参照：006工人F308–F319近处动作→F320–F335拉开→F336–F367线缆总量；007手术F298–F301建立→F302–F309推头部→F310–F314拉开→F315–F339较宽读取；007图纸F358–F378（14.931598–15.765766）读图，F383–F387（15.974308–16.141141）看建筑，F393–F395再读图。
- 验收：拉开后新增的环境关系足以改变观众理解；不是只把同一张图缩小；如果再往返一次，确实增加一个对照而不只是多晃一下。
- 误判边界：不要将007手术误简化成只“近→远”；本镜已有“中近→更近→宽”。图纸没有证据证明建筑由纸变出，更没有建造完成这一因果链。

### 方法四：用有归属的前景遮挡和视差建立临场感，别拿它掩饰主体错误

- 执行：安排能说明观察位置的栏杆、路杆、人物边缘；主体经过遮挡时保持运动方向，遮挡后马上恢复识别。若生成出错，不能把一整段糊／遮挡当成修复成功。
- 可直接参照：009 F61–F72（2.033333–2.400000）深色近景遮住客机后才切；006鱼缸F274–F307（11.428095–12.804471）街杆遮住车与人部分；006 F496–F500（20.687354–20.854188）近侧摩托掠过观众／栏杆。
- 验收：前景、主体、远景的速度层次有差异；前景遮挡对象具有位置来源；若有藏切，单独审方向、光线、身份与尺度连贯。
- 误判边界：前景遮挡不是自动证明真实实拍或空间正确；F61–F72深色物可称树干／立柱形前景，未核实其确切物体身份。

### 方法五：收尾时先把标锁进仍在运动的末镜，再切背景黑

- 执行：最后一镜继续完整运动，Logo固定屏幕坐标覆盖一个短桥接段；到黑底时仅切背景，不重复做Logo进入动画；黑底读取后硬切短署名。以BB品牌实际字标排版，不复制原作品牌。
- 可直接参照：006 F500无标→F501叠标（20.895896）→F512实景仍动→F513背景黑（21.396396）→F548仍Logo→F549署名（22.897898）。12帧叠标、36帧黑底是本原作精确节奏，可作为比较标尺。
- 验收：在背景切黑前后叠出Logo轮廓，中心与尺度不跳；末镜不是先冻结；同屏信息能在真实播放速度读清。
- 误判边界：该方法来自006，不说007／009也都先叠实景；本轮未重新连续复核它们片尾。0.5秒和1.5秒不是BB本片必须机械照抄的数字，更多信息必须重新做阅读测试。

## 5. 声音工具与试听声明

本轮检查了本环境可执行命令与已暴露工具：本机有`ffmpeg`、`ffprobe`、`ffplay`；未找到`aplay`或`paplay`，未看到`/dev/snd`设备。暴露工具中有外部语音增强／摘要能力，但它们不是把本地声音送到本模型进行真实听觉审片的已验证接口，而且本任务禁止外发，因此未调用。

结论应严格写成：**本轮没有实际试听。存在播放器命令不等于本模型已经接收到、听到了音轨，也不足以承诺真实试听成功。** 本轮不作曲风、低频力度、音量舒适、现场声比例、节拍落点、音效质量或声画“通过”结论。

本轮只核验原文件确实有AAC 44.1kHz双声道音轨。旧`reference-audit.md`中的22.05kHz单声道及BPM数字属于历史分析描述／候选，不是本轮原音轨格式、重算或听感。此次未重算BPM、未看波形推听感、未认定剪点精准卡拍。007／009曲名即使来自片尾文字，也只证明署名出现，不替代听到并核对实际音轨。
