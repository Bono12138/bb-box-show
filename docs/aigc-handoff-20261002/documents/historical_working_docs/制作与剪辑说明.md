# BB箱子第一期：A/B原创节奏试听底稿

用途：约20秒真实质感荒诞事件快切的节奏讨论。两条均为24秒试听草稿，不是最终成片音乐。尚未实际听审，不评价“好听”或保证听感。

| 拍点/段落 | A：100 BPM | B：104 BPM | 剪辑用途 |
|---|---:|---:|---|
| 每拍 | 0.600秒 | 0.577秒 | 可以落动作，也可以故意晚半拍 |
| 每小节（4拍） | 2.400秒 | 2.308秒 | 大段换场的候选位置 |
| 第一组4小节 | 0–9.600秒 | 0–9.231秒 | 建立事件，穿插半拍/四分之一拍短切 |
| 留白小节 | 9.600–12.000秒 | 9.231–11.538秒 | 踩镲后半段撤出，适合表情停留或荒诞揭示 |
| 后续推进 | 12.000–21.600秒 | 11.538–20.769秒 | 新场景或事件升级，鼓/低音切分位置可选 |
| 末段收束 | 21.600–24.000秒 | 20.769–24.000秒 | 稀疏末拍与衰减，适合片尾接入 |

不必每刀都踩底鼓。军鼓通常位于小节第2、4拍并略延后9毫秒；可跨重拍保留真实动作，使用踩镲弱拍或低音切分做局部强调。若主片严格20秒，先在小节附近收尾，再接独立片尾；这份24秒音频不应直接硬截作最终配乐。

制作：Python标准库直接合成降频正弦底鼓、噪声/正弦军鼓、短噪声踩镲、正弦低音及原创短音型。A留白较多，B底鼓/低音切分较密；确定性随机种子与全部事件时间保存在parameters-and-validation.json。generate.py可重建，两种速度的音型均非歌曲采样。

许可/来源：没有外部采样、第三方乐器音色库、旋律引用、歌词或人声。未安装软件，未购买、开户或调用付费API。没有调用外部代理。代码与合成素材为本任务原创制作；不宣称法律意义的版权登记或排他权已核实。

格式：主WAV为44.1kHz/16bit/立体声，约4.23MB。preview WAV为22.05kHz/8bit/立体声，约1.06MB，采用相邻采样平均降采样与量化抖动，体积为主WAV约四分之一；试听版音质较低，剪辑应使用主WAV。系统AAC/Opus编码器未能编码，因此未生成M4A/MP3。

验收状态：技术检查通过但未试听。主WAV时长24.000秒，双声道，峰值约−2dBFS，削波样本0；起始12ms平滑起音，末段音符自然衰减并预留650ms淡出包络，首尾样本为0。实际听感、踩镲是否刺耳、与画面相合及最终混音仍需人耳听审。参数JSON保留峰值、RMS、样本与事件数据，不能作为听感评审的替代。
