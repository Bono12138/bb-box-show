# D2两场几何测试结论
2026-09-30 16:43 UTC。只验证固定实体/机位，不是摄影/人物动作成品，不新增付费API。

## 结论
假相机空间可行候选：五人始终在同一位置，镜筒始终朝向他们；固定机身右侧后延板从右前偏侧挡住画师头/手，连续绕到后偏右时才暴露纸、正在画的手和画师。初角度能见少量腿，这是普通相机操作者的自然存在，不提前暴露手绘机关。末角度机身遮挡部分嘉宾合理，不要求每帧五人无遮挡。正式输入图还必须让机身/镜筒像真实相机、减少大留白、把绘画身份与纸上同组人形稳定下来。几何侧板不是巨型冰箱造型批准。

车顶空间可行候选：三座同排，驾驶在左。首构图三张脸/麦克风与方向盘同框，下层车辆未显露；连续向后下撤后，三人固定座椅、车顶、空驾驶舱和方向杆到车身的连接点可见。座位和转向连接在实体坐标里存在，没有中途加人或换车。方向杆进入屋顶连接点足以交代关系，不需剖面。首镜“敞篷驾驶”的期待能否成立仍须真实相机/汽车/光线图审，不以灰模当最终摄影。

另做真实厚度1.5cm、IOR1.45透明玻璃终点测试（Cycles光线追踪、48采样、无去噪）：在这一前侧角度与柔和环境光下，前/侧玻璃后空座仍可见；这只验证所选光线/视角，不承诺任意背景反光都清楚。正式图必须再次检查玻璃不要镜面封死。

## 自审范围
每条固定几何37个连续机位，已看首/中/尾并以逐机位接触表检查全部37张，无实体跳换、无隐藏切镜。视频540×720、30fps，无声音：假相机3.8秒114帧；车顶3秒90帧；全解码无错误。37个空间采样被输出为30fps，不能把这种测试帧率叫真人/生物连续动作完成。
