## 一、必须同时保留的制作要求
1. 全片为二十多秒的荒诞短片蒙太奇。所有场景与成片画幅统一3:4。结尾仅是一部分，不能反客为主。
2. 真实相机捕捉荒诞现场的质感：真实皮肤、布料、水、泥土、金属与重量接触；自然或实际灯具光，允许轻微曝光不均和现场凌乱。不是塑料CG、卡通、广告棚拍。加噪点不能替代真实材质。
3. 人类以亚洲面孔为主，允许不同种族，不固定同一阵容；允许外星人、无四肢陨石等非人嘉宾，只要场景合理、看得出做节目。
4. 真人节目常规4–6人。AIGC各场景可为3、4、5、6人，必须变化，不能全部三人。背景动作人物不计入节目嘉宾人数。
5. 场内连续镜头，不通过硬切特写制造节奏；可突然放大、拉远、横移、绕拍、旋转、移焦，但每次有明确揭示对象。场间允许硬切，场景及角色无需叙事相连。
6. 焦点服从笑点。看到客人不等于必须始终对焦客人；轮到背景事件或道具揭密，必须让它清楚。不能用浅景深虚掉关键事件，也不要毫无目的地来回抽焦。
7. 环境提供主要动态和冲突。嘉宾始终自然交谈，眨眼、呼吸、身体随载具运动，不是僵硬雕像，也不夸张抢戏。无需精排每个触手、每个出拳。
8. 每景要看出变化和后果，不能全部“静坐→突然冲出东西”。混用角色错位、工具错用、机关揭示、力量反差、时代错位和环境升级。
9. 前三秒立即有看点，镜头时长不必整齐。音乐要燥、有推动力；参考有说唱人声。未试听确认的音乐不能写已通过；实际视频素材尚未生成。
10. 荒诞有内部合理性：骑猪一人一猪并考虑负重；水下人有供氧装备；鲨鱼水罩覆盖鳃部，不是只罩嘴；车顶驾驶有可读转向连接；手绘相机有一致的机身、工作台与遮挡几何。
11. 提示词优先写事件与相机路径、焦点、揭示先后；细枝末节留模型发挥。秒级意图不等于模型能帧级执行，最终节奏靠剪辑。
12. 品牌片尾不依赖我们的真人、真实录音或固定拍摄场地。保留BB箱子；兔子可不用。本期只招募多人喜剧聊天节目，不混入课程社群业务。
13. 片尾必须先叠Logo在最后一景，Logo不消失、不换位置、不缩放，下方画面硬切黑。随后按参考切信息，不能另开一个广告片。
14. 信息须包含节目是什么、对标罗永浩《X字路口》、深圳南山、筹备与招募、全网同名、AI/Codex制作说明。不得编造既有班底、场地、薪资或分成。署名最终按实际工具核对。
15. Kimi是可选工具，dot负责设计和验收。此轮云端工作，不启动正在休息的Mac；新资料尚未同步回Mac。
