来源：https://www.buck.co/work/playgrounds-in-motion
实际取得22.955秒官方案例片，完整解码，按0.5秒抽帧核对46帧。前半通过现场、街景、舞台、观众切换景别；约11.5秒开始把品牌字形压在现场上，14.5秒让字形成为大面积图形，18秒回收为黑底紧凑字标。它用同一个可识别形状承担场景间连接，并非每屏重新发明装饰。官网说明也明确将N/M波浪形延伸到实拍、3D和其他媒介。

## 画面与声音的具体变化
- 延续用户认可“比之前好”的原兔子方向；不再生成电竞字标，不写对标节目名称。
- 信息两镜各做一件事：节目定位→地点与参与；最后一屏统一呈现标识与参考。
- 108 BPM原创合成节奏，短暂弱化→重音进入，增加中低频谐波让手机也能听到低频存在；立体声高频轻移动、过渡扫音与短金属落音。不是只放大音量。
- 末段6秒让用户能连上下文听，不再只交孤立片尾。仍没有说唱人声；最终配乐未确定，当前是节奏试验。
- 所有故事依然是静帧后期移动，不是完成的AI视频动作，也未借此验收连续运镜和真实质感。
