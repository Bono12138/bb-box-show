# C｜106 BPM 原创器乐节奏测试

22.642秒，10小节，4/4拍。用于剪辑节奏评审，不是最终配乐。开头直接底鼓、低音与低和弦重入（2ms防爆音起音），无前奏。

| 时间（秒） | 节奏变化 | 剪辑候选 |
|---:|---|---|

一拍0.566038秒；半拍0.283019秒；四分之一拍0.141509秒。军鼓落小节第2、4拍。无需每刀踩底鼓，可保留真实动作跨拍，并选择弱拍或scratch短节奏做局部强调。全部实际事件时间另见C_events.csv；静音窗口会遮住窗口内事件，剪辑以表中实际停顿为准。

与旧稿的制作差异：更短的底鼓衰减、更集中的军鼓瞬态、带谐波的短低音切分，踩镲采用稀疏变型，不连续机械铺满；加入两次完全停顿及重入，移除旧稿高音短旋律，改为低和弦与有限scratch-like噪声。C与旧稿均以−2dBFS峰值为目标，未用提高峰值替代编排变化。

素材/工具：仅Python标准库、确定性随机数和原创数学合成。无外部采样、音色库、歌曲旋律引用、歌词或人声；scratch-like来自程序噪声，未冒称真实唱盘或人声。未安装新软件，未调用外部代理或付费API。

文件：C_106BPM_master.wav为32kHz/16bit/立体声，约2.90MB；C_106BPM_preview.wav为16kHz/16bit/立体声，约1.45MB，使用抗混叠FIR降采样，剪辑优先用master。generate_c.py、C_parameters_QA.json与C_events.csv可编辑/复现音色、事件、速度及停顿。

技术QA：完整读取两个WAV；核对实际时长、采样率、双声道、16bit、峰值与削波，首尾样本及停顿边界平滑包络。详细测量见C_parameters_QA.json。**未实际试听**；是否够燥、是否吸引注意、是否有刺耳音及和画面的配合均待真实听审，不以代码与技术数据冒充听感判断。
