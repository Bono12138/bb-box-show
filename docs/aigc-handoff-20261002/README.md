## 接手要点

3:4、真实摄影、亚洲主体为主，单场 3–6 位嘉宾且人数有变化；笑点和关键背景要清楚。场内尽量连续镜头，环境事件推动发展，跨场可切换，不能每场都靠巨大物突然闯入。先审全片节奏，再审片尾。

片尾采用“Logo 先叠在仍运动的故事上，再只把底图切黑”的交接。后续信息须解释深圳南山多人聊天喜剧节目的筹备与招募，不混课程销售。最新要求禁止直接写对标节目名、Reference 和参考片来源标志；旧文档与图片中的这些内容均非当前规范。真实工具标识可按核实后的工具链与使用条件设计，暂不分发独立标识文件不构成创作禁令。

正文、七场顺序、20+5 秒工作候选、片尾、音乐均未最终锁定。V1/V2/V3/V5/D4 被否决，V6 有进步但未达标准；V7 和 D5r1 是局部候选，不能称为全片。生成服务、API、版本、预算与付费调用尚未授权。
