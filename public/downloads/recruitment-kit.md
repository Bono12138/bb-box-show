我们正在给 BB 箱子找话题。

这是一个准备在深圳录制的中文多人喜剧聊天节目。

比如，你在哪一刻发现自己装不下去了？

你可以带自己的经历，也可以带一个想继续追问的问题。
见面时先聊聊，录制和公开再分别确认。

如果你也想坐到桌边，去网站的“参与”页面找我们。

## 拍摄前检查

- [ ] 当前进度和招募角色已核对。
- [ ] 出镜者同意本次录制及公开用途。
- [ ] 场地、设备与背景物品使用已确认。
- [ ] 口播中的每项事实都有依据。
- [ ] 屏幕、白板和文件中的个人信息已清理。
- [ ] 已按实际机位录短段并回听声音。
- [ ] 画面中的每一行字都能独立读懂。
- [ ] 报名入口指向实际可用的 /join/ 页面。

## 剪辑与发布检查

- [ ] 字幕逐句回听，称呼与数字正确。
- [ ] 字幕断在完整词语或自然短句之间。
- [ ] 标题、封面、说明和结尾入口一致。
- [ ] 没有把草案写成已经执行的规则。
- [ ] 没有把候选人员写成已确认成员。
- [ ] 音乐、图片和其他素材已确认使用权。
- [ ] 最终版本由发布负责人确认。

发布记录：平台、账号、文件版本、发布时间、实际链接。
发布后再检查页面、声音、字幕和入口。
