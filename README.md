# BB 箱子

BB 箱子是一档正在深圳组建的多人喜剧聊天节目。每次由 4–6 个人围坐聊天，其中包括一位负责节奏和话题转换的主持人。

这个网站是项目的公开入口。它先介绍节目和当前需要的人与资源，再逐步公开组建进度、幕后工作方式和可以复用的项目记录。

[打开 BB 箱子网站](https://bono12138.github.io/bb-box-show/)

## 当前阶段

- 招募聊天成员和制作伙伴
- 寻找适合围坐聊天的场地、收音和拍摄支持
- 收集真实故事、话题和合作资源
- 准备第一次试聊

网站里的参与表单目前用于演示填写流程，尚未连接真实提交入口。

## 本地运行

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm run build
npm run test:sites
```

网站由 GitHub Pages 自动发布。
